## Assignment 1: Vertebral Column Data Set

Assignment 1 studies the UCI Vertebral Column Data Set as a binary
classification problem. The task is to classify patients as Normal or
Abnormal using six biomechanical measurements related to the pelvis and lumbar
spine.

The assignment covers:

- Exploratory analysis using scatterplots and boxplots
- A specified training and test split
- Euclidean K-nearest neighbors classification
- Selection of the number of neighbors, $k$
- Evaluation using classification metrics and error rates
- A learning curve based on different training-set sizes
- Comparisons of alternative distance metrics
- Weighted KNN classification

The complete Assignment 1 notebook and its data files are available in the
[assignment-01](assignment-01/) directory.
